eat_hwp_raw 설명서
==================

한글 문서의 내용을 LLM(로컬 Ollama 또는 Claude API)에 보내, 커서 자리에 들어갈 글을 받아 넣는
도구입니다.


1. 시작하기
-----------
- 한글에서 단축키 Ctrl+] 를 누르거나, "AI 문서" 탭의 "AI 작성" 버튼을 누르면 이 창이 뜹니다.
- 창은 한글과 따로 실행됩니다. 답을 기다리는 동안에도 한글을 계속 쓸 수 있습니다.


2. 기본 사용 순서
-----------------
1) 한글 문서에서 글을 넣을 자리에 커서를 둡니다.
2) 아래 프롬프트 칸에 요청을 씁니다. 예: "앞 문단을 세 줄로 요약해 커서 자리에 넣을 글을 써줘"
3) "보내기"를 누릅니다(Ctrl+Enter도 됨, Enter는 줄바꿈).
   - 보낼 때 한글의 지금 문서 전체를 읽어 커서 위치 표시와 함께 LLM에 보냅니다.
   - "다른 열린 문서도 함께 보내기"를 켜면 한글에 열려 있는 다른 문서도 참고 문서로 함께 보냅니다
     (아래 4 참고).
4) 대화 칸에 답이 나오면 읽어 보고, "커서 위치에 삽입"을 누르면 문서에 들어갑니다.
   - 답을 받기만 해서는 문서가 바뀌지 않습니다.
   - 넣을 수 있는 답은 마지막 답 하나입니다. 같은 답을 여러 번 넣을 수 있습니다.


3. 글이 들어가는 곳
-------------------
- 보낼 때 읽은 문서(원래 문서)에만 넣습니다.
  - 그 사이 다른 문서 탭으로 갔으면 원래 문서로 돌아가 넣습니다.
  - 원래 문서를 닫았거나 다른 이름으로 저장했으면 넣지 않고 대화 칸에 알립니다.
- 원래 문서 안에서는 "삽입"을 누르는 순간의 커서 자리에 넣습니다. 커서를 옮겼으면 옮긴 자리입니다.
- 그때 블록이 선택돼 있으면 블록을 지우고 그 자리에 넣습니다.
- 글자 모양은 아직 지정하지 않습니다. 커서 자리의 모양을 따릅니다.
- 넣은 뒤 되돌리려면 실행 취소를 여러 번 눌러야 할 수 있습니다(블록 지우기, 모양, 글자가 따로 남음).


4. 메인 창
----------
- 창 제목: "eat_hwp_raw — 대상 문서: 파일 이름". 대상 문서는 글을 넣을 문서입니다. 창을 열 때 한글에서
  보고 있던 문서이고, 보낼 때마다 그때 보고 있는 문서로 바뀝니다. 참고 문서와 헷갈리지 않게 확인하세요.
- LLM 상태 줄(맨 위): 지금 설정의 LLM 서버 상태입니다.
  ✔ 작동 중 / ✖ 연결 안 됨 / ✖ 인증 실패 / ✖ 키 없음 / ✖ 오류
- 설정 요약 줄: 쓰는 모델, LLM에 보낼 문서 형식, Claude API 키 입력 여부
- "다른 열린 문서도 함께 보내기": 켜면 한글에 열려 있는 다른 문서를 읽어 참고 문서로 함께
  보냅니다. 비슷한 문서를 옆에 열어 두고 양식이나 내용을 참고하게 할 때 씁니다.
  - "문서 고르기…": 열려 있는 문서 목록에서 보낼 문서만 체크합니다. 고른 적이 없으면 모두 보냅니다.
    고른 뒤에 새로 연 문서는 다시 골라야 들어갑니다. 고른 내용은 이 창을 닫으면 사라집니다.
  - 읽는 동안 한글 화면의 문서 탭이 잠깐 바뀌었다가 원래 문서로 돌아옵니다.
  - 다른 문서의 내용은 바뀌지 않습니다. 글은 원래 문서에만 넣습니다.
  - 보내는 양이 늘어납니다. 로컬 LLM은 한 번에 읽을 수 있는 양이 작으니 필요한 문서만 열어 두세요.
  - 대화 칸의 답 앞에 📄 대상 문서와 📎 참고 문서가 나뉘어 보입니다.
- 대화 칸: 보낸 요청(▶ 나)과 받은 답(◀ AI)이 시각과 함께 쌓입니다.
  - MCP 도구를 불렀으면 답 앞에 ⚙ 줄로 보입니다. 이 줄은 문서에 넣지 않습니다.
  - 문서에 넣은 결과는 ↳ 줄로 남습니다.
  - 각 요청은 따로입니다. 앞의 대화는 LLM에 보내지 않습니다.


5. 설정 창("설정…")
-------------------
"확인"을 누르면 저장하고 적용합니다. "취소"는 바꾼 값을 버립니다.

[LLM 연결]
- Claude API 키: 넣으면 Claude API로 실행합니다. 저장하지 않으며 창을 닫으면 사라집니다.
  Claude API를 쓰면 문서 내용이 외부 서버로 전송됩니다.
- 로컬/OpenAI 호환 서버 주소: 비우면 환경 변수 설정(기본 http://127.0.0.1:11434/v1)을 씁니다.
  같은 네트워크의 공용 Ollama 서버를 쓸 때 그 주소를 넣습니다. 예: http://192.168.0.10:11434/v1
- 모델: 목록에서 고르거나 직접 입력합니다. 비우면 환경 변수 설정을 씁니다.
- "상태 확인": 지금 칸에 적은 키·주소로 서버를 점검하고 모델 목록을 받아 옵니다.

[LLM에 보낼 문서]
- Markdown (기본): 제목·표 구조가 남아 대부분의 경우에 알맞습니다.
- 평문: 글자만 보냅니다. 가장 짧습니다.
- HWPML 원문 / HWPML 파일: 글자·문단 모양까지 보냅니다. 길어서 큰 모델에 알맞습니다.

[MCP 서버]
LLM이 참고 문서를 직접 찾아 읽게 하는 도구 서버입니다. 한 줄에 서버 하나를 적습니다.
#으로 시작하는 줄은 쓰지 않습니다.
  네트워크 서버:  docs = http://192.168.0.10:8000/mcp
  로컬 프로그램:  hwp2md = "C:\tools\hwp2md-mcp.exe" --root C:\참고문서
- "MCP 확인": 서버마다 붙어 보고 도구 개수나 실패 이유를 보입니다.
- 도구를 지원하지 않는 모델이면 MCP 없이 보냅니다.

[시스템 프롬프트]
- 고정 프롬프트: 프로그램이 정한 규칙입니다. 고칠 수 없습니다.
- 사용자 지정 지침: 문체, 분야 용어, 기관 작성 규칙 등을 적습니다. 고정 프롬프트 안의 표시된
  자리에 들어갑니다. 비우면 붙이지 않습니다.


6. 문제 해결
------------
- "✖ 연결 안 됨": Ollama가 켜져 있는지, 서버 주소가 맞는지 확인합니다.
- "model not found": 그 모델이 서버에 없습니다. 모델 칸에서 목록의 모델을 고르거나,
  서버에서 ollama pull 로 받습니다.
- "✖ 인증 실패": Claude API 키를 확인합니다(sk-ant- 로 시작).
- 답이 비거나 엉뚱함: 더 큰 모델을 쓰거나, 문서 형식을 Markdown이나 평문으로 바꿔 봅니다.
  실행환경 LLM은 한 번에 읽을 수 있는 양(컨텍스트)이 작아 긴 문서는 잘릴 수 있습니다.
- "문서에 넣지 못함": 원래 문서를 닫았거나 이름이 바뀌었는지 확인합니다.


7. 파일 위치
------------
모두 %USERPROFILE%\.eat_hwp_raw 아래에 있습니다.
- settings.txt: 서버 주소, 모델, 문서 형식
- system_prompt.txt: 사용자 지정 지침
- mcp_servers.txt: MCP 서버 목록
- chats\: 문서·API별 대화 기록과 로그(eat_hwp_raw_gui.log)
